# WIndows SpeedUP - Windows Optimization Commands Tool

## Overview

KUDDA.exe is a user-friendly Windows optimization tool designed to streamline common system maintenance tasks through a graphical interface built with Tkinter. It provides easy access to various system commands, helping you to optimize your Windows experience with just a click!

## Features

- **User-Friendly Interface**: Intuitive design allowing quick access to essential commands.
- **Command Tooltips**: Hover over buttons for descriptions of each command.
- **Command Confirmation**: Ensures you confirm before executing potentially impactful commands.
- **Responsive Layout**: Adaptable grid layout that adjusts to different screen sizes.

## Supported Commands

Here’s a list of commands available in KUDDA.exe:

| Command                          | Description                                      |
|----------------------------------|--------------------------------------------------|
| Clear DNS Cache                  | Clears DNS resolver cache                         |
| Release and Renew IP             | Releases and renews IP address                   |
| Clear ARP Cache                  | Clears ARP cache entries                         |
| Check and Repair Disk            | Checks for disk errors and repairs               |
| System File Checker              | Scans and repairs corrupted system files         |
| Optimize System Image            | Restores system image health                      |
| Check Network Connections         | Displays all network connections                  |
| Display Running Tasks            | Shows a list of active processes                  |
| Kill a Task (notepad.exe)       | Forces a program to close                         |
| List Startup Programs            | Lists all programs that run at startup           |
| Optimize Boot File               | Optimizes system boot files                       |
| Disk Cleanup Utility             | Opens disk cleanup utility                        |
| View Active Network Connections   | Lists active network connections                  |
| List Installed Programs          | Displays all installed programs                   |
| Disable Hibernation              | Disables hibernation mode                         |
| Enable Fast Boot                 | Enables fast boot mode                            |
| High Performance Power Plan      | Switches to high-performance power mode          |
| Manage Virtual Memory            | Opens virtual memory settings                     |
| Display Boot Config              | Displays boot configuration data                  |
| Reset Network Settings            | Resets all network settings                       |
| Reset Winsock                    | Resets Winsock entries to default                 |
| Clear Temporary Files            | Clears temporary files                            |
| List Services and Status         | Shows status of all services                      |
| Stop Unnecessary Services        | Stops unnecessary services                        |
| Enable Disk Write Caching        | Enables write caching for disk                   |
| Disable Indexing                 | Disables drive indexing                           |
| Disable Prefetch and Superfetch  | Stops prefetching and superfetching for SSDs    |
| Limit Virtual Memory Usage       | Opens memory management settings                  |

## Installation

1. **Download the KUDDA.exe** from the [releases page](https://github.com/ThiyansaRavidu/Win-Temp-Clear/releases).
2. Ensure you have Python installed on your system if you want to run the source code.
3. Run `KUDDA.exe` to launch the application.

## Usage

1. Upon launching, you will see buttons for various optimization commands.
2. Hover over a button to see a brief description of what it does.
3. Click a button to execute the command. You will receive a confirmation prompt before the command runs.
4. Enjoy a more optimized Windows experience!
